# Vibes Layer Images

Place the following PNG images in this directory (with transparent backgrounds):

## Required Files

1. **lion-walk.png** - Full-body male African lion striding right, ~1024x640px
2. **lion-head.png** - Front-facing Lion of Judah head, square 768x768px
3. **ganja-leaf.png** - Seven-point cannabis leaf, square 512x512px

All should have **transparent backgrounds (alpha channel)** and be photorealistic.

generated by Nano Banana 2.
